# UPPAAL traceability

The traceability of the UPPAAL models (`uppaal/corrected-v2/`) to automated tests lives in a single document: [docs/traceability-uppaal.md](../traceability-uppaal.md).

It covers all 39 properties of the telemetry, commands and authentication models (including the authentication properties this page used to mark out of scope), the `verifyta` status, and the model-versus-code divergences. This page is kept so existing links from [README.md](README.md), [AUDIT.md](AUDIT.md) and [VERIFICATION.md](VERIFICATION.md) keep working.
